# CoachIQ Diagnosis Simulator

A terminal-based clinical decision-making game built in pure Python 3 — zero dependencies, runs on any machine instantly.

Work through 10 real athlete injury cases across cricket, football, swimming, athletics, basketball, tennis, rugby, gymnastics, and cycling. For each case: read the history, select investigations, use a hint if needed, make your diagnosis, and read the evidence-based management plan.

## How to run
```bash
python3 coachiq_simulator.py
```

No pip install. No dependencies. Just Python 3.

## What this demonstrates
- Full ANSI terminal UI with colour-coded output
- 10 clinically accurate cases with real examination findings
- Real clinical tests: Lachman, Ottawa rules, Clarke's, Neer's, McMurray, stork test
- Weighted scoring engine with hint penalty system
- Persistent leaderboard saved to JSON
- Randomised case order each session
